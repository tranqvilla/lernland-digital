Räume deinen Desktop auf

Auf dem Desktop liegen 20 Dateien wild durcheinander: Texte, Musik und Bilder. Sortiere jede Datei in den richtigen Ordner – so findest du später alles wieder.

🗂️

Hilfe, mein Desktop ist voll!

Auf dem Desktop gibt es drei Ordner. In jedem Ordner stecken zwei Unterordner:

    1. Doppelklick auf einen Ordner öffnet ein Fenster.
    2. Ziehe Dateien mit gedrückter Maustaste in einen Ordner.
    3. Klicke auf eine freie Stelle und ziehe einen Rahmen – so wählst du mehrere Dateien auf einmal aus.
    4. Mit der rechten Maustaste kannst du Dateien ausschneiden, kopieren und einfügen.
    5. Oben im Fenster siehst du die Pfadleiste. Sie zeigt dir, wo du gerade bist.
